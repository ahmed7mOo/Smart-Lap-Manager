## 📖 Overview

**Smart Lab Manager** is a smart laboratory management system designed to automate and simplify the administration of computer laboratories in educational institutions.

The system provides centralized control over devices, users, schedules, maintenance operations, and laboratory resources through a modern web-based platform.

---

## 🎯 Project Objectives

- Manage computer laboratories efficiently.
- Monitor and control devices remotely.
- Organize laboratory schedules.
- Track maintenance operations.
- Manage users and permissions.
- Generate reports and statistics.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/username/Smart-Lab-Manager.git
```

2. Enter the project folder:

```bash
cd Smart-Lab-Manager
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the server:

```bash
uvicorn main:app --reload
```
